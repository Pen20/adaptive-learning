
# STACK-AI-Math-Course

**STACK-AI-Math-Course** is an advanced, adaptive learning platform designed for university-level mathematics. It leverages Generative AI to provide real-time grading, personalized feedback, and infinite practice generation for students mastering Linear Algebra and Differential Calculus.

## Features

-   **Adaptive Learning Paths**: Structured courses in Linear Algebra and Differential Calculus with topic-based progression.
-   **AI-Powered Grading**:
    -   Submit open-ended math solutions.
    -   Receive instant, detailed feedback on correctness and reasoning.
    -   **Multi-Model Support**: Choose between GPT-4o, GPT-4o-mini, Mistral, Llama 3, and Phi-3 for grading as needed.
-   **Interactive Practice**:
    -   **Infinite Drill Generation**: AI generates unique practice problems based on your recent mistakes.
    -   **Beautiful Math Rendering**: Full LaTeX support via KaTeX for crisp mathematical notation.
    -   **Mobile Optimized**: Responsive design that looks great on desktops, tablets, and smartphones.
-   **User System**:
    -   **Secure Authentication**: Powered by Clerk (Google, Email, GitHub).
    -   **Onboarding Flow**: Mandatory profile completion (University, Birthday) for personalized experiences.
    -   **Mastery Tracking**: Visual dashboards to track progress and mastery scores per topic.
-   **Modern Tech Stack**: Built for performance and scalability.

## Technology Stack

-   **Frontend**: [Next.js 15](https://nextjs.org/) (App Router), [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
-   **Backend & Database**: [Convex](https://convex.dev/) (Real-time database & backend functions)
-   **Authentication**: [Clerk](https://clerk.com/)
-   **UI Components**: [Shadcn/UI](https://ui.shadcn.com/), [Lucide React](https://lucide.dev/)
-   **Math Rendering**: [KaTeX](https://katex.org/), `react-katex`
-   **AI Integration**: OpenAI API, Hugging Face Inference

## Getting Started

### Prerequisites

-   Node.js 18+ and Bun
-   A Clerk account (for authentication)
-   A Convex account (for database)
-   An OpenAI API Key (for AI features)

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/stack-ai-math-course.git
    cd stack-ai-math-course
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    # or
    bun install
    ```

3.  **Environment Setup**:
    Create a `.env.local` file in the root directory and add the following keys:

    ```env
    # Convex
    CONVEX_DEPLOYMENT=... # Generated by npx convex dev
    NEXT_PUBLIC_CONVEX_URL=...

    # Clerk
    NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=...
    CLERK_SECRET_KEY=...
    CLERK_WEBHOOK_SECRET=...

    # OpenAI
    OPENAI_API_KEY=sk-...
    ```

4.  **Run Development Server**:
    You need two terminals running simultaneously:

    **Terminal 1 (Backend - Convex):**
    ```bash
    npx convex dev
    # or
    bunx convex dev
    ```

    **Terminal 2 (Frontend - Next.js):**
    ```bash
    npm run dev
    # or
    bun run dev
    ```

5.  **Open the App**:
    Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment (Vercel)

This project is optimized for deployment on [Vercel](https://vercel.com).

1.  **Push to GitHub**: Ensure your project is pushed to a GitHub repository.
2.  **Import to Vercel**:
    -   Go to Vercel Dashboard -> Add New -> Project.
    -   Select your GitHub repository.
3.  **Configure Environment Variables**:
    -   Add all the keys from your `.env.local` (`NEXT_PUBLIC_CONVEX_URL`, `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `OPENAI_API_KEY`, etc.) to the Vercel Project Settings.
4.  **Convex Production Build**:
    -   In your terminal, run `npx convex deploy` to push your schema and functions to the Convex production environment.
    -   Update the `NEXT_PUBLIC_CONVEX_URL` in Vercel to point to your **Production** Convex instance (not the dev one).
5.  **Deploy**: Click "Deploy". Vercel will build and host your application.
